# flip.cold.fyi

The Flip - a cited field guide to music sampling. cold.fyi deep dive No. 11, by Third Polar Arch. GitHub Pages serves `main` from the repo root.

- `src/build.py` regenerates the whole site from `src/content/` (`parts/*.md`, `frag/*.json`, `frag/*-sources.tsv`). `STRICT=1` fails on gap markers or unknown footnote keys.
- `src/og.py <sources>` redraws the share image.
- Data for agents: `/breaks.json`, `/cases.json`, `/machines.json`, `/glossary.json`, `/timeline.json`, `/sections.json`, `/sources.json`, `/llms.txt`.
